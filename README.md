# P8

A radio in your Mac's menu bar, with eight preset stations.

**[Download the latest version →](https://github.com/zappika/p8-releases/releases/latest)**

Get `P8-<version>.zip`, double-click it, and move **P8** to Applications. It's signed
and notarized, so it opens normally. P8 lives next to the clock: press 1–8 to switch
stations, space to pause. It checks for new versions once a day.

More: [sarper.se/p8](https://sarper.se/p8) · Privacy: [sarper.se/p8/privacy](https://sarper.se/p8/privacy)

This repository holds releases only.
